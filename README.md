# ERP System - Supply Chain Management 🚚

A comprehensive ERP (Enterprise Resource Planning) system designed for supply chain management. This platform streamlines operations with modules for **Purchase Management**, **Sales Management**, and **Accounts Management**, enabling efficient workflow and real-time updates.

## Technologies Used ⚙️

- **Frontend**: Angular, Tailwind CSS 🎨
- **Backend**: Node.js, Express.js ⚡
- **Database**: MongoDB with Mongoose 🗄️
- **Real-Time Communication**: Socket.IO 🔗

## Features ✨

### 🌟 Core Modules:
- **Purchase Management** 🛒: 
  - Manage supplier details and purchase orders.
  - Track incoming inventory and generate reports.

- **Sales Management** 💼: 
  - Handle customer orders and invoicing.
  - Monitor sales performance with real-time updates.

- **Accounts Management** 💳: 
  - Maintain financial records, including income and expenses.
  - Generate balance sheets and profit/loss statements.

### 🔧 Additional Features:
- **Inventory Management** 📦: Track stock levels and manage product lifecycles.
- **User Roles and Permissions** 🔑: Role-based access for Admins, Managers, and Staff.
- **Reports and Analytics** 📊: Visual dashboards for insights into business performance.
